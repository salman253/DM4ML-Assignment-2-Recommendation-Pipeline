The project has been switched from synthetic data to the official GroupLens MovieLens latest-small public educational dataset. The execution environment used to assemble this ZIP could not reach files.grouplens.org, so no MovieLens dataset or MovieLens-derived metric values are embedded here. On the user's first local run, `python -m src.pipeline` downloads the official archive, executes the full pipeline, and creates validation/evaluation outputs. The final report is generated from those actual local run results.
